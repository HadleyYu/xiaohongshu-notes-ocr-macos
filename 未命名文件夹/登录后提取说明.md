# 登录后提取｜2026-09-18

之前只能识别短链接，但请求被小红书带到了登录页。本次新增专用浏览器登录流程，不是继续重试同一条未登录请求。

## 现在怎么操作

1. 关闭旧的提取终端窗口，重新双击外层「小红书文字提取.command」。
2. 粘贴分享链接或分享文案，按回车。
3. 阅读本地登录状态保存提示，按回车同意打开专用浏览器；输入 `q` 可取消。
4. 在弹出的浏览器里自行扫码或登录。验证码也由你手动完成。
5. 登录后不要关闭浏览器，回到终端再按回车，开始提取。

下次运行会使用相同的独立登录资料；登录是否仍有效由小红书决定。如果仍要求登录，请在这个专用窗口里完成，而不是只在日常 Chrome 中登录。

## 保存与隐私

Markdown 仍保存到本工具目录，不去“文稿”。专用浏览器资料保存在同目录下的隐藏文件夹 `.login-browser`，包含登录状态，权限限制为当前用户可访问。不要把这个文件夹连同工具一起发给别人或上传。

浏览器控制端口由浏览器自动分配，仅绑定本机回环地址；工具只连接自己资料目录记录的端口，不默认连接日常 Chrome 的 9222 端口。我们未复制、读取或上传日常浏览器 Cookie，也未替你登录。本次修改和测试未启动真实浏览器。

短链解析与正文提取共用你确认过的同一个浏览器会话。完成后可以关闭专用浏览器窗口；本地登录资料仍保留，便于下次使用。

## 已验证与未验证

已运行独立会话地址、回环地址限制、取消不启动浏览器、同会话传递和短链接回归测试，37 项通过，记录见 `login-regression.xml`。测试使用模拟浏览器和网络；不能等同于已登录你的小红书账号或已取得真实笔记正文。首次真实登录和登录后提取仍需要你按上述步骤完成。

此工具仍只提取配文和图片文字；视频讲话不包含在内，需要额外语音转写。
